# Frontend improvements and verification

24 October 2026. Baseline: `ed945629cfe04b7097c6a94e8699603f2b9b5792`. See [the prioritized audit](frontend-ux-audit.md) for each issue, affected surface, current/expected behavior, rationale, scope and priority.

## Implemented improvements

1. **Workspace integrity.** Every configuration/knowledge mutation carries the workspace for which its form was rendered. Server actions compare it against current membership-derived context before any write. Old tabs receive a clear error instead of writing to a newly selected business. Workspace UI remounts on switching; switch/create failures and pending states are visible. Controlled inputs preserve drafts on rejected submissions.
2. **Reliable customer operations.** Inbox separates successful POSTs from failed refreshes. Unconfirmed replies retain their original nonce and can be replayed without creating a new message. Poll generations, sequence checks and conversation state versions prevent older reads from rolling back ownership/AI state. Refresh recovery clears live-update errors. Earlier pages preserve scroll position and loaded delivery records. A small API read fix fetches delivery truth for the displayed message page, including historical failed/unconfirmed sends.
3. **Explicit AI handoff.** Claim, reply and release keep their existing backend semantics. Resume uses an accessible confirmation explaining that it releases a claim and applies to the next customer message. Failed test resume is reported and can be retried. Paused tests clearly require explicit resume.
4. **Connected setup.** Overview has data-derived setup progress, clearly optional agent review, published-only knowledge guidance, isolated test guidance and channel next steps. Metrics link to their records. Agent goals explain the contact collection dependency; the internal setup brief is accurately described as an internal note excluded from runtime instructions. Saved feedback is hidden when further edits are unsaved.
5. **Knowledge lifecycle.** Drafts survive rejected saves. Published edits warn that saving unpublishes the item. Publishing shows processing feedback and does not report completion before confirmation. Confirmed operations lead to the relevant status view with a visible notice and item highlight. Archive/delete have accessible cancel/confirm dialogs. Title search, active filters, totals and pagination make older content reachable.
6. **Conversations and leads.** Long tests load the latest context; saved history has stable, chronological pages. Leads and conversation lists have scoped filters and pagination. Mobile lead cards replace the wide table on small screens. Lead details explain qualification and link to the original real or test conversation without adding unsupported CRM behavior.
7. **Channels.** Exact-origin validation retains input on failure. Clipboard rejection offers selectable embed code. Local widget prerequisites are explicit and the UI explains that the demo creates a real Inbox thread. Instagram preserves managed setup, shows attention/disconnected states and confirms disconnection. Messaging-window and delivery semantics remain server controlled.
8. **Shared experience.** Dismissible native mobile navigation supports Escape/focus behavior, closes on navigation and marks Test Agent as its own destination. The header wraps on narrow screens. Shared controls have clearer focus/disabled states, larger targets, stronger secondary text contrast, consistent feedback and text wrapping. Existing reduced-motion behavior remains. Authentication, callback and query failures offer product-focused recovery.
9. **Security patches.** Next.js is pinned to 16.4.1; targeted overrides pin the vulnerable fast-uri 3.1.8/4.2.2 resolutions to 3.1.9/4.2.3. The lockfile retains unrelated dependency versions. No major dependency upgrade was introduced.
