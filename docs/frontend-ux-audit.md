# Avenlyo frontend UX and workflow audit

Audit baseline: `ed945629cfe04b7097c6a94e8699603f2b9b5792` (24 October 2026). This report distinguishes source-confirmed defects from design recommendations. All requested routes, shared components, server actions, same-origin API handlers, shared schemas, API handoff logic, migrations, and existing tests were inspected before implementation.

No Critical frontend workflow defect was found. The later dependency audit confirmed Critical Next.js advisories (F17 below). The existing backend protects tenant membership, owner configuration, published-only knowledge, explicit AI resume, delivery semantics, test-channel isolation and durable idempotency. Those boundaries should be preserved.

## Route coverage

- `/auth/sign-in`, `/auth/sign-up`, `/auth/callback`: credential validation, confirmation, session verification and redirects.
- `/workspaces`, `/app`: creation, switching, selected membership, setup and activity.
- `/app/agent`: all supported goals, tone, contact fields, mandatory handoff and internal brief.
- `/app/knowledge`, `/app/knowledge/new`, `/app/knowledge/[id]`: Text/FAQ draft/edit/publication/archive/deletion and revision checks.
- `/app/test-agent`, `/app/conversations`, `/app/conversations/[id]`: durable test turns, same-key retries, saved history and explicit resume.
- `/app/leads`, `/app/leads/[id]`: qualification, customer-stated facts, channel and original thread.
- `/app/inbox`, `/app/inbox/[id]`: real threads, ownership, pause/claim/reply/release/resume, delivery ledger and polling.
- `/app/channels`, `/chat-demo`: exact origins, widget installation, managed Instagram and messaging-window constraints.
- `/app/settings`: business name, identity and read-only membership.

## Implementation and verification

Implementation groups and actual verification results are recorded in `frontend-ux-verification.md`. No schema migration, database reset, hosted database mutation, major dependency upgrade or live customer/provider send is part of this change. The only dependency changes are the same-series security patches described below.

## Dependency finding discovered during verification

**F17 / Critical — existing dependency advisories.** The baseline dependency audit reported 2 Critical, 1 High, 4 Moderate and 4 Low advisory entries. Next.js 16.4.0 was covered by GHSA-2464-fhr4-w9xw (image optimization), GHSA-673q-mjm6-r5xr (typed arrays in cache functions), and GHSA-p3m5-59mp-jv5r (Server Actions denial of service). These are confirmed dependency version matches, not claims that a particular exploit path was demonstrated in Avenlyo. Expected behavior is a supported patched runtime. The minimal remedy is Next.js **16.4.1**, plus compatible patched fast-uri transitive resolutions in the lockfile. This is a justified patch-only exception to the otherwise unchanged dependency set; no major version or application API is changed.

Primary references reviewed on 24 October 2026:

- https://github.com/vercel/next.js/security/advisories/GHSA-673q-mjm6-r5xr
- https://github.com/vercel/next.js/security/advisories/GHSA-p3m5-59mp-jv5r
- https://github.com/fastify/fast-uri/security/advisories/GHSA-w74x-v6f9-j3xg

**F18 / High — delivery states on historical Inbox pages.** `apps/api/src/channels/routes.ts` fetched the latest 100 delivery records independently of the requested message page. Loading earlier messages could therefore omit failed/unconfirmed delivery labels. The minimal backend read change fetches delivery records for the actual page's message IDs, with the existing workspace and conversation scopes. The client retains already loaded delivery records. No delivery operation or policy changes.

**F19 / Medium — mobile claim discoverability.** CI screenshots at 320px confirmed that the ownership card could place the required claim action below a long thread and the disabled reply composer. Claim now appears in the conversation header before messages, with the same conflict/pending guards. A mobile browser regression verifies it is initially visible and can unlock a human reply without resuming AI. Frontend only.
